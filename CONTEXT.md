# GAZELL3D

GAZELL3D presents Aither torrent pages in a Gazelle-inspired layout.

## Language

**Release name**: The original name of a torrent, including its technical attributes and release group. The original remains meaningful even when a shorter name is displayed.

**Torrent dropdown**: The expandable view of a torrent's details, description, files and media summary beneath its listing.

**Media summary**: A readable account of a torrent's video, audio and subtitle information, accompanied by the unchanged original MediaInfo or BDInfo text.

**Torrent group**: Torrents associated with a title, organized by release type and, for television, season or episode.

**Trump report**: A report proposing that one torrent replace another, with a reason and optional comparison screenshots.

**Seadex icon**: An interactive release recommendation marker supplied by Seadex. Its behavior and association with the original release must survive changes to the displayed layout.
